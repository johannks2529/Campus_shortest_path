ADMIN TOOLS
Data accuracy
  • Locations, paths and distances come from campus.csv (the same data as the desktop app).
  • Scale: 0.6 m per map pixel and 84 m/min walking, unless a path has a fixed length. Times are estimates.
  • Floor plans: real scans for CLC only; other blocks can be uploaded.
  • Admin: edits stay as a draft in this browser until you publish them to GitHub or download campus.csv.
